# PROJECT_CONTEXT
**Objective:** interactive 3D digital twin prototype + dashboard + state-space model (dx/dt=Ax+Bu, y=Cx+Du) of Ghazi Barotha, for an EE university project. Teacher brochure (`source_data/original_brochure.pdf`) is the primary source. Simulation only; no real-plant link or validation.
**Tools (free):** Python 3 + NumPy/SciPy/pytest; Streamlit + Plotly dashboard (done, Phase 2); Plotly 3D in a local Streamlit component (Phase 3, done). Target: Windows laptop (i5-1245U, 16 GB). Claude Free: keep phases small.
**Phases:** 0 setup (done), 1 model + state-space (done), 2 governor + dashboard (done), 3 3D scene (done), 4 scenarios/integration/testing (done), 5 report + demo guide (done: documentation/technical_report.md, reports/*.docx/.pdf).
**Source-data rules:** never invent plant data; published values come from `source_data/source_data_register.csv` (64 rows, with PDF page); assumptions only in `_ASSUMED` in `backend/model.py`, logged in `documentation/assumptions_and_limitations.md`; changing a published value requires a CHANGELOG entry. Tag everything published / calculated / assumed / simulated.
**Model:** states [h_p, Q, y, w, delta], inputs [y_cmd, P_load, Q_in], outputs [Q, h_t, P_gen, f]; equations in `documentation/mathematical_model.md`. Operating point: pond 334 m, y=400/460, Q=400, h_t=69, P=254.51 MW (calculated).
**Governor (Phase 2, all ASSUMED):** PI+droop, e=(w_ref-w)-R(y-y_set), y_cmd=clip(y_set+Kp e+xi), dxi/dt=Ki e+Kb(y_cmd-unsat), servo rate limits; R=0.05, Kp=1, Ki=0.2, Kb=2, rates 0.10/0.20 pu/s. Poles: -2.66, -0.55, -0.204+/-0.127j, 0, +3.2e-6 (pond, physical).
**Architecture:** app.py -> backend/simulator.py -> backend/governor.py -> backend/model.py -> source_data register. Dashboard live updates via `st.fragment(run_every=0.6)`; chart repaint blank ~3% at 0.6 s (measured).
**3D (Phase 3):** app.py tab "3D plant" -> `view3d()` fragment (same timer as `live()`, read-only) -> backend/plant3d.py (SceneState.from_simulator, build_figure, build_geometry with provenance) -> backend/scene_geometry.py; rendered by frontend/plant3d/index.html via backend/plant3d_component.py (Plotly.react keeps the user's camera; plotly.min.js copied from the installed package, git-ignored). Layout schematic; levels/penstock/channel published.
**Scenarios + state space (Phase 4):** backend/scenarios.py (5 scenarios = input schedules on the real Simulator; build_scenario validates, never clips; ScenarioPlayer splits steps at events; assess = limit/validity checks; results_zip = CSV+metadata). backend/state_space.py (linearize_at nominal or current-gate equilibrium, open or closed loop; export_zip; compare_with_run via lsim). ui/scenario_panel.py, ui/state_space_tab.py. check_setup.py.
**Launch:** `python -m streamlit run app.py`; tests: `python check_setup.py`; `python -m pytest` (210) and optional `python tests/e2e_browser.py`, `python tests/e2e_browser_3d.py`, `python tests/e2e_browser_phase4.py` (need Playwright).
