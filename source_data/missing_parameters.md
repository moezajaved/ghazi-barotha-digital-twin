# Parameters NOT in the brochure

None of these may be invented. When needed, use a typical textbook value, tag it `Assumption` in `documentation/assumptions_and_limitations.md`, and keep it easy to overwrite.


## Generator
- Rated MVA and power factor
- Rated voltage (brochure value unconfirmed)
- Speed / number of poles
- System frequency (50 Hz expected, not stated)
- Inertia constant H
- Reactances and time constants
- Excitation system data

## Turbine/governor
- Rated speed
- Runner diameter
- Efficiency curve
- Gate servo and governor parameters
- Water starting time

## Hydraulics
- Headpond surface area and level-volume curve
- Minimum operating level
- Tailwater rating curve
- Penstock losses and wave speed
- Channel roughness
- Tarbela release profile

## Grid/transformer
- Transformer impedance
- Tap ratio
- Grid short-circuit level
- Load profile
